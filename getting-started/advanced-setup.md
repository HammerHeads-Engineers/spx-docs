# Advanced Setup & Automation

This hub collects workflows you can layer on once the basics are running:

* Load Python classes directly as SPX models for code-defined simulations.
* Capture and restore simulation snapshots for reproducible experiments.
* Drive the platform inside unit tests (MiL) to validate client applications automatically.
* Wire SPX into CI/CD so regressions are caught before deployment.

Dive into the subpages for detailed steps, prerequisites, and example snippets.
